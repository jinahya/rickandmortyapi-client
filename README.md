# rickandmortyapi-client

Client libraries for accessing the [Rick and Morty API](https://rickandmortyapi.com/).

## Modules

| Module                          | Description                                        |
|---------------------------------|----------------------------------------------------|
| `rickandmortyapi-client-types`  | Defines interfaces and classes for binding values. |
| `rickandmortyapi-client-common` | Defines interfaces and classes for client modules. |
| `rickandmortyapi-client-jre`    | Uses `java.net` and `java.net.http` packages.      |
